# 100層ダンジョン

iPhone Safari対応の単一HTMLローグライクRPG試作。`index.html`をGitHub Pagesで配信するか、ローカルの静的Webサーバーで開いてください。

## v0.2.0 — 戦闘と成長

- 5列6行の石版探索。隣接石版を開放し、もう一度タップして移動・イベント発生。
- 主人公①・冒険者の1人戦闘。初期能力はHP100・SP30・攻撃12・防御8・魔力10・魔法防御8・素早さ10。
- 通常攻撃、ガード、スマッシュ（SP4、武勇3でSP3）、ファイア（SP5）、キュア（SP6）。ファイア・キュアは対応ツリーで習得。
- 行動選択後、素早さ順に処理。同速は主人公が先。ガードは行動順にかかわらずターン開始時から有効。
- 物理ダメージは `max(1, round((攻撃 - 防御×0.5) × 技倍率))`。スマッシュ倍率1.5。
- ファイアは `max(1, round(魔力 + 8 - 魔法防御×0.5))`。属性耐性はまだ未実装。
- キュアは `round((20 + 魔力) × 回復補正)`。ガードは最終被ダメージを切り捨て半減、最低1。
- 通常戦闘は経験値5、強敵10、レア15。同額のGも獲得。敵は3ターンごとに魔法攻撃。逃走は成功率65%、失敗時は敵が行動。逃走成功で報酬なし・マスは探索済み。
- 3系統×3段階のツリー。必要経験値は各10→20→30、系統をまたいで自由に取得。
  - 武勇：攻撃＋3 → 最大HP＋20 → スマッシュ消費SP−1。
  - 魔導：ファイア → 魔力＋3 → 最大SP＋10。
  - 加護：キュア → 魔法防御＋3 → キュア回復量＋20%。
- 最大HP/SP増加時は現在値も同じ量だけ増加。戦闘中と結果画面では取得不可。
- 行動ごとに自動保存。戦闘途中も再開可能。全滅と新しい冒険では成長・経験値・Gをリセットし、最高到達階だけ保持。
- 10層ごとの帰還地点は1回だけ全回復。中断・再開では回復しない。
- v0.1の探索セーブは別キーで残すが、能力値・戦闘の互換性がないためv0.2へ移行しない。

宝箱の装備・スキル、ランダム装備、仲間・4人編成、ショップ、合成、ボス、深層バランスは未実装。現段階は序盤の戦闘・育成検証用です。主人公名・種族・イラストは未確定のため仮表記です。

石版画像は `assets/stone/tier-01.webp`〜`tier-10.webp` があれば使用。未配置の場合はCSSの石版表示にフォールバックします。
