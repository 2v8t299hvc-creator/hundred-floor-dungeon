# 100層ダンジョン v0.9

単一HTMLのソロ探索RPG。主人公を操作し、同行サポートと召喚ゴーレムが自動行動します。GitHub Pagesで `index.html` を配信。


## v0.9 — 探索マスと全モンスターの絵柄統一

- 宝箱・HP回復・MP/SP回復・商人・階段・戦闘マスに、輪郭線とセル影をそろえた専用画像。強敵・レア戦闘は枠色でも区別。
- スライム・ピクシー・ウンディーネを描き直し、階層の守護者と銀のウィスプにも専用画像を追加。人型モンスターは成人男性としてデザイン。
- 過去の進行中セーブで種族情報がない敵も、戦闘種別に応じて画像を表示。

## v0.8 — 主人公の絵柄に合わせた遺跡と石版

- 犬獣人主人公案の太めの輪郭とシンプルなセル影を基準に、遺跡背景と未開放の石版を描き直し。
- 青緑の石・金の装飾・ルーンの意匠を継承。細かい質感や光沢を減らし、大きな形で表現。
- 主人公の立ち絵はデザイン決定段階。今回の画面更新は背景と石版。

## v0.7 — 大きな探索盤面と専用マスイラスト

- 盤面を最大520px、スマホは画面幅いっぱいに拡大。高さによる石版の縮小をやめ、短い画面は縦スクロール。
- 宝箱・HP回復・MP/SP回復に専用の透明イラスト。利用後は彩度を下げ、チェック印と「済」で表示。

## v0.6 — 石版を広げる探索・ウンディーネ

- 現在地を廃止。開放済み空白・処理済みイベントの隣接石版を自由に開放。
- 開放と利用を分離。宝箱や回復は開放後にタップ、戦闘は開放時50%で強制発動し、残りはタップで開始。魔法の遠隔開放は強制戦闘なし。
- マスの種別は処理後も表示。階段・商人・設備はタップして選択後、専用ボタンで利用。
- 浮遊は戦闘マス開放時の強制戦闘を5回回避する形に変更。
- 非ボスの強敵を男性ウンディーネに変更。専用イラスト・水流の魔法攻撃。

## v0.5 — 開放と移動・ピクシー

- 隣接する石版は1タップで開放して移動し、イベントを発生。魔法の遠隔開放はその場で行う。
- 通常敵に男性の「いたずらピクシー」を追加。スライムより低HP・高素早さで、魔防に対する妖精の光で攻撃する。通常戦闘で各個体50%の確率で登場。
- 既存のセーブ・進行中の戦闘も引継ぎ可能。

## v0.4 — 石版と魔法の冒険

- 明るい手描き風の遺跡背景、透過の石版・スライムを追加。探索、基地、戦闘を同じ世界観に統一。
- HP・MPを常時表示するコンパクトなHUD、画面下の冒険メニュー、スライムの待機モーション。
- 能力・素材・巻物一覧、成長、仲間、長いログは開閉式パネルへ移動。巻物・設備の選択も同じパネル形式に統一。
- 探索で対象マスを指定する際は巻物パネルを閉じ、石版を直接選べるようにする。
- 縦持ち・横持ちに対応し、主要画面はブラウザの表示領域内に配置。小さい画面では最小高さのためスクロール可能。
- 既存v0.3の保存形式・戦闘数値・巻物消費は維持。画像の詳細は `assets/visual/README.md`。

## v0.3の魔法システム

- 戦闘の入口を「攻撃・ガード・スキル・逃げる」の4択に変更。スマッシュ、巻物、ポーションはスキル内。
- 7属性×5段階＝35魔法。場面・属性解放レベル・巻物枚数・MP・対象条件を確認し、有効な発動時だけ巻物1枚とMPを消費。
- MPとSPを分離。スマッシュはSP4、魔法はMP。初期MP40、初期属性は炎Ⅰ・光Ⅰ。
- ツリーで属性Lv.0〜5を順に解放。各段階の経験値は10×解放後Lv。基礎成長は1段階ごとに必要経験値が10増加。
- 数値型魔法は個別に最大3段階、1段階＋15%。ゴーレムは経験値40で攻撃・守護のいずれかに不可逆分岐。その他の魔法変化は内容を決めてから追加。
- 探知・遠隔開放・列開放・全開放は移動とイベント発生から分離。予約ダメージと気絶は入場時に反映。
- 宝箱と一部の戦闘で巻物を取得。宝箱では素材も入手。商人から10Gでランダム巻物と魔素を購入可能。
- 光Ⅱで設備を選んで開放済み空白マスに設置。鍛冶台で装備作成・強化、醸造台でポーション作成、練魔台で全35巻物を作成・分解。
- ？マスからサポート仲間が加入。最大3人を保有、1人同行。仲間にHPがあり、倒れた仲間を闇Ⅳで蘇生。
- 複数敵、10の倍数階の強敵をボス扱いにし、割合ダメージ軽減・突風無効を適用。
- 中断保存は巻物、効果、ゴーレム、トラップ、仲間、戦闘中にも対応。v0.2から基本成長・探索を移行し、置換したツリー能力は経験値を返還。進行中の旧戦闘は再戦する。

## タイムトラベル

戻る階層数は `max(1, min(30, floor(魔力 / 2)))`（仮設定）。1層より前には戻れません。現在の魔力に応じた戻り先をメニューに表示。

巻物とMPを支払ったあと、主人公の成長・経験値・装備・素材・残り巻物・仲間・HPなどを引き継いで、戻り先の階を新しく生成します。再び降りる各階も新規生成となり、敵や宝箱から再度報酬を獲得できます。以前の階の履歴は保持しません。生成番号を更新し、探索済み・探知・予約攻撃・施設は新しいマップへ引き継ぎません。

## 魔法試験モード

基地の「魔法試験モード」で31Fから開始。全属性Lv.5、各巻物8枚、MP300、経験値2000、素材100、サポート3人で試せます。

通常の冒険と別の保存キーを使い、通常の進行・最高到達階に影響しません。「中断して基地へ」→「通常の冒険へ」で通常進行に戻ります。試験も独立して再開でき、「新しい冒険」で試験だけリセットできます。

## 仮数値と細部

- 魔法のMP消費・威力・回復量・素材費は調整用の暫定値。全リストは [MAGIC.md](MAGIC.md)。
- 基礎ダメージは `max(1, round((威力 - 対応防御×0.5) × 補正))`。
- 通常攻撃は攻撃力、スマッシュはその1.5倍。ファイア等の小魔法は魔力＋8、大魔法は魔力×3＋20、ライトニングは魔力×1.8＋12。
- キュアは20＋魔力、フルウォッシュは40＋魔力×2、マージウィンドはMP60回復（消費MP3）。
- デスクラウドは最大HP基準で25%、ボス5%、単体。吸血は直接与ダメージの30%。
- 鉄壁とガードは乗算で合計75%軽減。火炎の障壁はその後に半減し、障壁自身が減らした分だけ反射。盾はその後にダメージを吸収。
- ウォーターシールドは加算せず現在値と新規量の大きい方を採用。不死鳥は重複不可。盾と不死鳥は戦闘・階層を越えて残る。
- 行動順は素早さ順、同速は主人公が先。効果時間は原則ターン終了時に減少し、発動ターンも含む。
- 凍結は3回の敵の行動機会を止め、解除後5ターン耐性。ライトニング気絶は1回、解除後2ターン耐性。ダメージで解除されない。
- スロウは最初の行動を飛ばし、2回目に行動。敵単位でカウントする。
- ヘイストは対象敵のバフ・デバフ・耐性を3ターン進める。継続ダメージのまとめ払いは現段階ではなし。
- リコールは主人公の時間制限バフを元の最大に戻す。ストップは戦場の効果なので対象外。
- ストップは発動ターンを含む2ターン。敵と双方の効果時間・トラップの待ち時間を止め、停止自体だけ減る。主人公・仲間・ゴーレムは行動可能。
- トラップは設置ターンを数えず、時間が進む4ターン後の終了時に発動。戦闘終了で消滅。
- 浮遊は移動だけで残り回数を消費。無視したマスは未使用のまま。階段の操作は可能。
- アイシクルアローの予約攻撃は戦闘開始前の処理として適用し、戦闘を確実に発生させるため最低HP1を残す。アースシェイクは今回新たに開いた戦闘マスだけに気絶を予約。
- ゴーレム基本型はHP＝主人公最大HP、攻撃＝魔力＋8、かばう40%。攻撃型はHP0.6倍・攻撃1.8倍・かばう15%、守護型はHP1.5倍・攻撃0.6倍・かばう85%。主人公が無敵ならかばわない。
- 同行仲間の仮名・行動：剣士ロルフ（3ターンごと追撃）、薬師フィン（HP30%以下で25回復、再発動4ターン）、守衛ブラム（3ターンごと盾8）。敵は5ターンごとに生存中の同行仲間を攻撃する。

主人公選択、装備の特殊効果、敵の属性相性、全100層のバランスと専用ボス、未定の魔法変化は今後拡充。深層はまだバランス調整前です。

## 確認

35魔法の実発動、一度のタップで開放・移動・イベント発生、魔法の遠隔開放、MP・巻物の条件、状態異常と耐性、時間停止・遅延発動、蘇生、設備、タイムトラベルの再生成と引継ぎ、全100階生成、セーブ互換、試験保存分離、不正データと保存失敗を検証。

## 冒険者セット（★1）
7部位：冒険者の剣（攻撃3〜4）、サークレット（魔力1〜2）、ボロマント（防御2〜3）、木のお守り（魔防1〜2）、皮の手袋（攻撃1〜2）、皮の靴（素早さ1〜2）、なべのふた（防御1〜2）。一式は初期の持ち物に入り、宝箱からもランダムに1個入手。持ち物で比較・装備・解除・1G売却。戦闘中は変更不可。旧防具は身体枠に引継ぎ。セットボーナスはありません。

装備画面は中央の犬の冒険者と周囲7部位のアイコン、かばんのアイコングリッド、選択中の装備詳細で構成。冒険者セット7点のオリジナル透過イラストを追加。キャラの衣装は固定で、装備の変更は周囲の枠と能力値に反映されます。
